# LCS Engine: AI-Powered Investment Education Platform

LCS Engine is an interactive learning platform that teaches systematic investment strategies through AI-guided education and paper trading simulation. Built for aspiring quants, retail traders, and finance professionals seeking to master quantitative trading approaches.

## 🎯 Overview

LCS Engine combines large language model technology with quantitative finance principles to deliver personalized, adaptive learning experiences. The platform guides users from fundamental concepts through advanced strategy development, with real-time feedback and performance tracking.

## ✨ Key Features

### AI-Powered Learning
- **Strategy Generation**: Claude AI analyzes market conditions and generates custom trading strategies
- **Personalized Guidance**: Adaptive learning paths based on user experience level
- **Interactive Q&A**: Real-time answers to quantitative finance questions

## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- Anthropic API key

### Installation

1. Clone the repository:
```bash
git clone https://github.com/OhTarnishedOne/LCS_Engine.git
cd LCS_Engine
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Set up your Anthropic API key:
   - Create a `.streamlit/secrets.toml` file
   - Add your key: `ANTHROPIC_API_KEY = "your-key-here"`

4. Run the application:
```bash
streamlit run streamlit_ui/app.py
```
